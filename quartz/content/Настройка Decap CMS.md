Я пробовал настроить эту headless CMS для GithubPages.
Оригинальная ссылка - https://decapcms.org/docs/install-decap-cms/

**Кратко:**
Все файлы находятся в  `admin` folder next to those. (When you've found the location, feel free to add it to these docs by [filing a pull request](https://github.com/decaporg/decap-cms/blob/master/CONTRIBUTING.md#pull-requests)!)

Inside the `admin` folder, you'll create two files:

```bash
admin
 ├ index.html
 └ config.yml
```
